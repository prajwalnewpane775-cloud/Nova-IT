SECURITY FIRST

Your account.
Your control.

Manage your account securely with modern authentication, private profile data and protected user access.

🔐

Secure Authentication

Your account is protected with encrypted authentication.

+

Every login is secured with Supabase Auth using encrypted tokens. Your password is never stored in plain text — it's hashed with bcrypt before saving. Session tokens expire automatically for your protection.

👤

Private Profile

Your personal data stays private and protected.

+

Your profile data is stored in Supabase with Row Level Security (RLS). Only you can read and edit your own information. No other user or third party can access your private data.

🛡️

Protected Access

Users can only access their own account data.

+

Row Level Security policies ensure each user can only query their own rows. API keys are scoped and rate-limited. Your account cannot be accessed by anyone without your credentials.
